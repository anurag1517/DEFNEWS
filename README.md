## Local Development Setup

If you prefer to run the application locally, follow these steps:

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Startup

1. **Install all dependencies:**
   Running this command at the root will automatically install dependencies for the frontend:
   ```bash
   npm install
   ```

2. **Start the frontend development server:**
   Running this command at the root will launch the Vite development server for the frontend:
   ```bash
   npm run dev
   ```

The frontend will be available at `http://localhost:5173`.
